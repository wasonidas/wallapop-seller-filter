# Security reporting

Do not put passwords, cookies, authorization headers or unredacted captures in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use it for a report that requires sensitive details. Otherwise, open an issue asking for a private reporting channel without including those details. No email address or dedicated private channel is configured by this file.

The extension has no backend, analytics or AI service. It makes ordinary requests to the configured Wallapop origin, which can include that origin's existing browser session. Seller IDs and listing source URLs are stored locally as described in the README. Build and browser-test artifacts must not include a real browsing profile.
